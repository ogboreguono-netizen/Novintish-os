# Novintish-os
 My original operating system project
Fusion OS

Novintish OS is my original operating system project.

My Vision

I want to create an operating system for computers inspired by useful ideas from Apple, Microsoft Windows, and Samsung.

Planned Features

- A beautiful and simple desktop.
- A taskbar and application launcher.
- Resizable application windows.
- A file manager.
- Customizable settings and themes.
- Notifications and quick settings.
- Security and privacy features.
- Support for computer hardware.

Development Goals

1. Learn the basics of programming.
2. Build a simple operating system kernel.
3. Boot Fusion OS in a virtual machine.
4. Create a graphical desktop.
5. Add applications and hardware support.

Project Status

Planning and learning stage.

This project will use original code and design.
